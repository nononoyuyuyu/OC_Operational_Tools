## 機能対応

| 元ツールの機能 | 新アプリでの実装 |
| --- | --- |
| Bot接続とToken保存 | 接続画面、任意の暗号化保存、次回の自動接続、保存済みToken削除 |
| Bot招待URL生成 | 設定画面から必要最小限の権限を含むURLをコピー |
| サーバー・チャンネル・ロール | 選択と一覧更新。同名チャンネルはカテゴリとIDで区別 |
| 日時・最小投稿数による抽出 | 日本時間の両端を含む期間、任意の終了日時、最小投稿数 |
| Bot除外・本文・添付URL | 個別の取得設定。本文・添付URLは初期状態では取得しない。スマホでは取得設定と機能を省く |
| プレビュー | PCは高さに応じたページ表示と投稿一覧。スマホは名前・処理予定のスクロール一覧 |
| 権限とロール階層チェック | チャンネルの権限上書きと保護ロールを判定。開始時と5秒または20人ごとに再検証 |
| ロール付与 | 対象者確認、保有済み・退出済みのスキップ、逐次実行 |
| ロール一括解除 | 全ページの取得、対象者一覧、注意事項へのチェック |
| キャンセル・進捗 | 処理状況表示、送信済みの結果を確認して停止、未処理行の記録 |
| CSV | PC・タブレットに投稿者・投稿・操作結果の出力UIを提供。スマホには表示しない。UTF-8 BOM、数式無害化、IDの桁落ち対策 |
| 操作履歴・再開 | 送信前後の永続記録、承認済みタスクからの再開、未確認対象の再照合、履歴のページ取得・詳細の必要時読み込み、任意の結果CSV自動保存 |
| 出力先 | Windowsは保存ダイアログ、Android・iOSタブレットはOSの共有メニュー |

元ツールのWindows専用フォルダ設定画面は、各OSの保存・共有操作に置き換えています。参照元のkakutei_rollerの設定・DPAPIファイル・CSVを自動移行する機能はありません。抽出条件は画面移動中に保持し、0.2.1以降は保存済みTokenで接続する場合、アプリ再起動時にも前回値を復元します。本アプリの0.2.xから0.3.0へのWindows保存先移行は別途対応しています。

## 0.1.1の修正と回帰検証

投稿抽出で「Discordの応答形式が正しくありません。」となる問題を修正しました。[RESTのMessage構造](https://docs.discord.com/developers/resources/message#message-object)では、サーバー内のメンバー情報を表す `member` は必須ではありません。省略時に補う空Mapの型がJSONオブジェクトの検査に通らず、正常な投稿も拒否していました。空Mapの型を明示し、投稿の `author` を読み取った後、既存のメンバー照合で表示名とロールを取得します。

修正前に、member省略・null・抽出からメンバー照合までの3件で同じエラーを再現しました。修正後は、空オブジェクト、部分member、不正な型と必須author欠落の拒否を含む追加7件が成功しています。架空のHTTP応答をJSONとして復号するテストであり、実Tokenや実際の投稿本文は使用していません。

## 0.4.0の再開・継続処理とデータ選択

2026年9月7日、Flutter 3.44.4でフォーマット、静的解析と自動テスト129件が成功した。実Bot Tokenと実Discordは使わず、復帰処理は永続記録を使うコントローラーと架空のDiscord状態で確認している。

- 応答を失う直前にロールが反映された場合、再照合で重ねて送信しない。古い承認済みタスクは未完了の人だけを扱い、別Bot、承認されていない解除、対象者列の不一致を拒否する。

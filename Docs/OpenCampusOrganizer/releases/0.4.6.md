# Open Campus Organizer 0.4.6

配布番号: `0.4.6+15`

## 修正内容

- Discord接続に世代番号を導入し、同じTokenで再接続した場合も、古い待機要求・再試行・読取結果を拒否する。送信済みのロール更新の成功応答は操作記録のため保持する。
- 最終の429応答で要求を終了する際も、次の要求に対するルート別・全体の待機期限を保持する。
- HTTP応答をストリーム受信中に1応答あたり8 MiBで制限する。Content-Lengthが欠落・過少でも実受信量で判定し、超過時は受信を中断する。更新の結果が不明な場合は未確認として扱い、超過応答を自動再試行しない。
- 待機中のHTTPクエリを呼出し時の値で固定し、破棄した接続の再利用を拒否する。
- 同じ保存キーの読取・置換・追記を直列化し、書込みの逆転と追記の喪失を防ぐ。固定名の一時ファイルは使わず、ランダム名で排他的に作成し、自分が作成した一時ファイルだけを片付ける。

## 互換性・確認範囲

設定・履歴の保存形式、Tokenの保管先、CSV出力、ロール操作の承認条件に変更はない。新しい一時ファイル名も既存Windowsアンインストーラーの削除対象形式に合わせている。

Windows・Android・iOSの共通処理に対する修正であり、OS固有の起動仕様やテーマ設定は変更しない。CIの回帰テストに加え、Windows・macOSでも通信と実ファイルI/Oのテストを実行する。最終結果はPR #9のCI記録を参照する。

詳細なリスクの前提と検証の限界は `安全性レビュー-20260909.md` に記載する。

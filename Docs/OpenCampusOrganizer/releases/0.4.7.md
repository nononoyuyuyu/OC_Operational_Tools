# Open Campus Organizer 0.4.7

配布番号: `0.4.7+16`

## 変更内容

- Windowsのタスクバー・現在のユーザーのスタートメニュー・デスクトップ・既存ピン留めで使うアイコンを、配色別の専用ICOファイルへ切り替えた。EXE内のリソース番号だけを変更する方式への依存をなくし、画像内容のSHA-256を名前に含めることでアップデート前の画像とも区別する。
- 対象ショートカットとウィンドウのアイコン参照を揃え、Shellへ対象画像の更新を通知する。同じ配色の再選択でも通知を再送する。アプリIDは固定し、ウィンドウIDの一時解除をキャッシュ更新の代わりに使わない。
- 5配色×9サイズのICO出力、画像を保持した状態での繰り返し切替、Shellが返す画像、変更通知の受信、インストーラー相当のショートカット再作成、書込失敗からの再試行を自動検証する。

## 検証範囲

テストはWindowsの実API・ICO・ショートカット・画像キャッシュを使用する。利用者の既存のタスクバーピン留めとWindows 11のスタート画面の描画結果は、配布前に手動確認する必要がある。詳細は [再発調査記録](../Windowsアイコン再発調査-20260922.md) を参照する。

設定の保存形式、Discordの操作、Android・iOSのアイコン処理は変更しない。

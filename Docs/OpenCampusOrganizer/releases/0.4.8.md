# Open Campus Organizer 0.4.8

配布番号: `0.4.8+17`。Windowsの実表示確認前の修正候補。

## 変更内容

- Windowsのテーマ適用で、ショートカットとウィンドウのアイコン参照を揃えてから表示更新を通知する。リンクを扱うCOMオブジェクトの解放も通知より先に完了する。
- テーマ変更・同色の再試行・Shell再初期化のたびに、Shellのアイコンキャッシュ更新、対象ショートカット、登録済みAppsFolder項目の順に通知する。DPI変更ではキャッシュ更新を行わない。
- ウィンドウのアイコン変更メッセージを受ける瞬間のプロパティ、通知時点のアイコン、再試行時の通知順序を自動検証する。

Shellへのキャッシュ更新通知に伴い、デスクトップのアイコンが一時的に再描画される場合がある。キャッシュファイルの削除やExplorerの再起動は行わない。

## 検証上の制限

0.4.7では画像取得APIのテストが成功した後も、利用者のタスクバーとスタートの表示で再発した。今回もAPIテストの成功を実表示の成功とみなさず、全5配色の反復切替と既存のピン留め表示を確認してから公開する。経緯と残る確認は [再発調査記録](../Windowsアイコン再発調査-20260922.md) を参照。

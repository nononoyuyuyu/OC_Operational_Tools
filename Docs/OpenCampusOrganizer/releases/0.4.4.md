# Open Campus Organizer 0.4.4

- Androidでテーマを変更すると操作画面が閉じる不具合を修正しました。ホーム画面のアイコンの色を変えても、開いている画面を維持します。
- Androidのホーム画面・OS設定・最近使ったアプリに表示するアプリ名を「OC」にしました。アプリIDと配布用署名は変更していないため、従来版へ上書き更新できます。
- mainへのマージ後、必要な検証が成功するとWindowsインストーラーと署名済みAndroid APKを自動公開します。

## ダウンロード

- Windows: `windows-x64-setup.exe` を実行してください。インストール先を指定でき、必要なVC++ランタイムを同梱しています。インストーラーとアプリ本体にはAuthenticode署名を付けていません。
- Android: 通常は `android.apk` を使用してください。容量を小さくしたい場合は、端末のCPUに合うAPKを選べます。設定・履歴を残すため、既存のアプリをアンインストールせずに更新してください。
- iOSはシミュレータービルドの検証対象です。今回の配布物にIPAは含みません。

## 検証

Flutterの解析・自動テスト、Windowsのビルド・アイコン・インストーラー検証、Androidのビルド・API 35上の起動と全配色の切り替え・画面復帰、iOSのシミュレータービルドを実行します。APKの署名・アプリID・バージョン・CPU構成と、公開前後の全添付ファイルのSHA-256を照合します。すべてのAndroid端末・ホームアプリでの動作を検証したものではありません。

# Open Campus Organizer 0.4.5

配布番号: `0.4.5+14`

## 修正内容

- Windowsでテーマを繰り返し変更した際に、タスクバーが古いアイコン情報を参照し続ける経路を修正した。ショートカットを保存し、変更通知を配達してから、最新の再起動情報と固定AppUserModelIDをウィンドウへ再通知する。タスクバーボタンの削除・再登録には依存しない。
- DPI変更は大小のウィンドウアイコンの更新に限定し、ショートカットの再走査とタスクバーの再通知を行わない。変更不要な読取専用ショートカットを誤って失敗扱いにしない。
- Windows・Androidに共通するOSアイコン更新を直列化し、連続選択や起動時の保存色復元で古い要求が最後の選択を上書きする競合を防いだ。未着手の中間色は省略する。
- 古い読込・保存・OS更新の失敗が最新の選択のエラー表示を上書きする問題を修正した。失敗後の同じ色での再試行、リスナーからの再選択、コントローラー破棄後の呼出しも保護した。

## 検証範囲

Windowsの実Win32ウィンドウとICO、ショートカット、プロパティ公開順序の回帰テストを拡張した。Androidでは5色を3周し、各色の二重適用でも起動アイコンが1個であることを検証する。共通処理には非同期競合の回帰テストを追加した。実行結果は本バージョンのPRとGitHub Actionsを参照する。

iOS・Webでは従来どおりアプリ内の配色のみを切り替え、OS・ブラウザーの静的アイコンを動的に変更する機能は追加していない。

自動テストは、利用者のWindows環境にある既存ピン留めの見た目や各Androidホームアプリのキャッシュ表示までは保証しない。設定・履歴の保存形式、Bot Token、Discordの権限・ロール操作に変更はない。

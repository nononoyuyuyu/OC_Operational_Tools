# OC_ThreeMonthBlankHighlighter v2 検証結果

実施日: 2026年9月11日

## レビュー結果

旧リポジトリの最新末尾判定と現リポジトリのREADME・必須CIを確認した。現リポジトリのmainには本ツールがなかったため、旧PRをそのまま誤った場所で更新せず、独立した新実装として追加した。

既存の末尾区間方針を維持し、直接塗りつぶしでは非該当へ戻った行の元色を安全に戻せない点を改善した。新実装はマーカー付き条件付き書式を管理する。前回の既存フィルタ削除・行グループAPIの障害を避けるため、それらのAPIを使用しない。

## 実施済みローカル検証

```bash
node --test Tests/OC_ThreeMonthBlankHighlighter/*.test.js
```

Node.js v22.16.0で55テスト成功、失敗0、スキップ0。23件のロジック試験、28件の統合モック試験、4件の安全性試験を実行した。末尾判定は4,096通りのパターンを別実装の順方向オラクルと照合した。上限試験は学生1,000人×日付300列を実際に配列生成して全件判定した。ローカル性能をGASの処理時間として扱わない。

## CI

PRの既存必須GASジョブで、新ツール全試験と既存抽出ツールとの結合読込を実施する。OCOのソース・バージョン・配布物は変更しない。CIの実行ID・確定結果はPRへ記録する。

## 未実施・限界

実際のGoogle スプレッドシートへの導入、Google側の条件付き書式の表示・優先順位、保護設定、Chrome/Safariでのダイアログはこの環境では検証していない。モック成功を実機成功として報告しない。

手動受け入れ手順: 元背景色が黄色の登録日セルを対象にして赤表示にし、後続日付へ値を入れて再実行し黄色へ戻ることを確認する。他の条件付き書式がある場合も対象外後に再適用されることを確認する。旧版で直接塗った赤は自動復元できない。

人の同時編集はDocumentLockで停止できない。実行中は対象データと条件付き書式の共同編集を避ける。

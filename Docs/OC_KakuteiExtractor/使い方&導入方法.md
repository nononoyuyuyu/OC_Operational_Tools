## 2. 使用前の準備

`スクリプト用シート`の`A2`へ開始日、`B2`へ終了日を`yyyy/MM/dd`形式で入力する。

```text
2026/04/19
2026/05/10
```

`学生情報一覧`には次の必須ヘッダーが必要である。

```text
学籍番号
名前
フリガナ
SA/TA
```

ヘッダー行は1行目でなくてもよい。その他の列は追加列として無視される。

## 3. 実行時の表示変更

実行時は次の処理を行う。

1. 手動で非表示にされた行を再表示する。
2. 通常フィルタの各列に設定された絞り込み条件だけを解除する。

**通常フィルタ自体は削除しない。** 実行後もヘッダー上のフィルタボタンとフィルタ範囲は残る。

### 3.1 行グループ

行グループは展開も折りたたみも行わない。実行前の開閉状態を保持する。

行グループが折りたたまれている場合でも、抽出処理は表示状態に依存せず、対象データを取得する。コピー漏れにはならない。

保存済みフィルタ表示も削除・変更しない。フィルタ表示を開いている場合は、閉じてから実行する。

## 4. 実行手順

1. `スクリプト用シート`を開く。
2. 開始日と終了日を入力する。
3. 実行ボタンを押す。
4. 1回目の確認画面で対象シート、期間、ヘッダー行を確認する。
5. 次の表示方針を確認する。
   - 通常フィルタ本体を残して条件だけ解除する。
   - 手動非表示行を再表示する。
   - 行グループの開閉状態は変更しない。
6. `はい`を選択する。
7. 2回目の確認画面で日付列一覧と行数を確認する。
8. `はい`を選択してコピーする。

ボタンへ割り当てる関数名は次のとおりである。

```text
runOC_KakuteiExtractor
```

## 5. フィルタが既に消えた場合の復旧

過去の旧版の実行によって通常フィルタが削除された場合、次の手順で再作成する。

1. `学生情報一覧`を開く。
2. ヘッダー行からデータ最終行・最終列までを選択する。
3. `データ`→`フィルタを作成`を選択する。
4. 必要だった絞り込み条件を手動で再設定する。

削除前の条件はツール側で保存していなかったため、自動的には完全復元できない。保存済みフィルタ表示が残っている場合は、条件再設定の参考にできる。

## 6. 表示状態のエラー

### 6.1 手動非表示行の再表示に失敗

次の趣旨のメッセージが表示される。

```text
手動で非表示にされた行を再表示できませんでした。
通常フィルタ本体と絞り込み条件は変更していません。
行グループの開閉状態も変更していません。
```

この場合、シート保護、編集権限、結合セルなどを確認する。

### 6.2 フィルタ条件解除に失敗

元の条件へ復元したか、復元できなかった可能性があるかをメッセージで区別する。通常フィルタ本体と行グループは削除・変更しない。

### 6.3 旧版の行グループエラー

次のメッセージが表示される場合は、Apps Scriptへ旧版の`Code.gs`が残っている。

```text
行グループを展開できませんでした。
```

最新版では行グループAPIを呼び出さないため、このエラーは発生しない。

## 7. データ仕様

| 列 | 値 |
| --- | --- |
| 学籍番号 | 必須、正規化後に半角英数字 |
| 名前 | 必須 |
| フリガナ | 必須。半角カタカナ、半角英数字、半角スペース、氏名用記号 |
| SA/TA | 空欄可。非空欄は半角英数字 |
| 日付セル | 空欄可。非空欄は`○`、`×`、`キャンセル`、`確定`、`定員` |

フリガナの氏名用記号は次のとおりである。

```text
- ' . / ( ) & _ ,
```

## 8. Apps Scriptの更新

1. `拡張機能`→`Apps Script`を開く。
2. 現在の本ツール用`.gs`ファイルを開く。
3. 内容をすべて削除する。
4. リポジトリの最新版`Source/OC_KakuteiExtractor/Code.gs`を全文貼り付ける。
5. 保存する。
6. Apps Scriptエディタとスプレッドシートを再読み込みする。

新しい`.gs`ファイルとして追加せず、既存ファイルを全文置換する。

`コピー確認.html`と`appsscript.json`に変更がないリリースでは、`Code.gs`だけを更新する。

## 9. 更新版の確認

1回目の確認画面に次の趣旨の文言が表示されれば、行グループ非操作版である。

```text
通常フィルタがある場合は、フィルタ自体を残したまま各列の絞り込み条件だけを解除します。

手動で非表示にされた行を再表示します。行グループは通常の非表示行とは別機能として扱い、開閉状態を変更しません。

抽出対象は表示状態や行グループの開閉状態に依存せず、全対象行から取得します。
```

旧版の次の文言が表示される場合は、最新版へ置換できていない。

```text
手動で非表示にされた行を再表示し、行グループを展開します。
```

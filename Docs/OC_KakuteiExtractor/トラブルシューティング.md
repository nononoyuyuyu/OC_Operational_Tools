## 2. `行グループを展開できませんでした`と表示される

### 原因

このメッセージは、行グループ展開APIを呼び出す旧版で発生する。

```text
行グループを展開できませんでした。
通常フィルタ本体と絞り込み条件は変更していません。
手動非表示行だけは既に再表示されている可能性があります。
```

利用者環境で必ずしも権限不足を意味しない。行グループが存在しないシートや、行グループAPIを適用できないシート状態でも例外となる可能性がある。

### 修正版

最新版では行グループ展開を抽出の必須処理から削除している。

- 手動非表示行は`showRows()`で再表示する。
- 通常フィルタ本体を保持し、絞り込み条件だけを解除する。
- 行グループの開閉状態は変更しない。
- 行グループが折りたたまれていても、その行を抽出対象に含める。

最新版では次のAPIを呼び出さない。

```text
expandRowGroupsUpToDepth
expandAllRowGroups
collapseAllRowGroups
```

### 更新確認

1回目の確認画面に次が表示されれば最新版である。

```text
手動で非表示にされた行を再表示します。
行グループは通常の非表示行とは別機能として扱い、開閉状態を変更しません。

抽出対象は表示状態や行グループの開閉状態に依存せず、全対象行から取得します。
```

次の旧文言が表示される場合は、Apps Scriptの`Code.gs`を最新版へ全文置換する。

```text
手動で非表示にされた行を再表示し、行グループを展開します。
```

## 3. フィルタが消えた

### 原因

さらに古い版は通常フィルタに対して`remove()`を実行していたため、条件だけでなくフィルタ本体とフィルタボタンも削除していた。

### 復旧

1. `学生情報一覧`を開く。
2. 元のヘッダー行からデータ範囲全体を選択する。
3. `データ`→`フィルタを作成`を選択する。
4. 必要な列の絞り込み条件を手動で再設定する。

旧版は元の条件を保存していないため、削除された条件をツールから完全復元することはできない。保存済みフィルタ表示が残っている場合は参考にする。

## 4. 最新版のフィルタ動作

最新版は次の動作を行う。

- フィルタ本体を削除しない。
- フィルタボタンと範囲を残す。
- 各列の絞り込み条件だけを解除する。
- 手動非表示行の再表示に失敗した場合はフィルタ条件へ触れない。
- 条件解除に失敗した場合は元条件へ復元する。
- 行グループを変更しない。

確認画面に次が表示される。

```text
フィルタ自体を残したまま各列の絞り込み条件だけを解除します。
```

## 5. 手動非表示行を再表示できない

表示例:

```text
手動で非表示にされた行を再表示できませんでした。
通常フィルタ本体と絞り込み条件は変更していません。
行グループの開閉状態も変更していません。
```

確認事項:

- 実行利用者に対象シートの編集権限があるか
- シート全体が保護されていないか
- 結合セルや特殊な行構成がないか
- 別の利用者が同時に構造変更していないか

この段階では通常フィルタ、条件、行グループは変更されない。

## 6. フィルタ条件を解除できない

### 元の条件へ復元したと表示された

退避した条件を再設定している。フィルタ本体は残っている。念のため各列の条件を確認する。

### 一部条件を戻せない可能性があると表示された

条件解除と復元の両方でエラーが発生した。フィルタ本体は削除していないが、一部条件が変更されている可能性があるため、全列の条件を確認する。

行グループの開閉状態は変更されない。

## 7. シート保護で中止された

編集できないシート保護を検出した場合、行や条件を変更する前に中止する。

シートの所有者または保護設定の管理者へ、行表示とフィルタ条件変更が可能な権限を依頼する。

## 8. その他の入力エラー

- 学籍番号: 必須、半角英数字
- 名前: 必須
- フリガナ: 必須、半角カタカナ・半角英数字・氏名用記号・半角スペース
- SA/TA: 空欄可、非空欄は半角英数字
- 日付セル: 空欄可、非空欄は許可5値

エラーに表示される物理行番号、A1セル番地、Unicodeコードポイントを確認する。

## 9. Apps Scriptへの更新手順

1. 対象スプレッドシートから`拡張機能`→`Apps Script`を開く。
2. 現在の本ツール用`.gs`ファイルを開く。
3. 内容をすべて削除する。
4. 最新版`Source/OC_KakuteiExtractor/Code.gs`を全文貼り付ける。
5. 保存する。
6. Apps Scriptエディタとスプレッドシートを再読み込みする。
7. 1回目の確認画面に行グループを変更しない説明が出ることを確認する。

新しい`.gs`ファイルとして追加せず、既存ファイルを全文置換する。

- シート保護の有無
- 実行利用者の権限

## 2. 目的

`学籍番号`および`SA/TA`に、見た目では判別しにくい空白、全角英数字、不可視文字が含まれている場合の誤判定を防ぐ。また、エラー行の認識違いを防ぐため、物理行番号、対象セル、実際の検出値を利用者へ提示する。

`学籍番号`は必須識別子、`SA/TA`は任意識別子として区別し、`SA/TA`の空欄を正常値として扱う。

## 3. 対象列

次の2列を識別子列として扱う。

- `学籍番号`: 必須
- `SA/TA`: 任意

`SA/TA`の値は、列名と同じ`SA`または`TA`に限定しない。`B65655`のような半角英数字文字列を許可する。また、各学生行の`SA/TA`セルは空欄を許容する。

## 4. 正規化

検証とコピーの前に、次を順番に適用する。

1. ゼロ幅スペース、ゼロ幅非接合子、ゼロ幅接合子、ワードジョイナー、BOMを除去する。
2. Unicode NFKC正規化により全角英数字を半角英数字へ変換する。
3. 前後のUnicode空白を除去する。

例:

| 元の表示値 | 正規化後 |
| --- | --- |
| `B65655` | `B65655` |
| ` B65655 ` | `B65655` |
| `　Ｂ６５６５５　` | `B65655` |
| `B65655`の末尾にゼロ幅スペース | `B65655` |
| 空文字、空白だけ、ゼロ幅文字だけの`SA/TA` | 空文字 |

正規化後の値をTSVへ出力し、変更検出用スナップショットにも使用する。元シートのセル値は変更しない。

## 5. 検証

### 5.1 学籍番号

正規化後の値について、次を検証する。

- 空欄ではないこと
- ASCII英数字`A-Z`、`a-z`、`0-9`だけで構成されること

### 5.2 `SA/TA`

正規化後の値について、次の規則を適用する。

- 空欄なら正常とし、空文字を返す。
- 非空欄ならASCII英数字`A-Z`、`a-z`、`0-9`だけで構成されることを要求する。

### 5.3 許可しない非空欄値

次は許可しない。

- ハイフン
- スラッシュ
- 値の途中の空白
- 値の途中の改行またはタブ
- ASCII英数字以外の記号

## 6. 実装上の分離

学籍番号には必須用関数を使用する。

```text
ocKakuteiValidateRequiredAsciiAlphanumeric_
```

`SA/TA`には任意用関数を使用する。

```text
ocKakuteiValidateOptionalAsciiAlphanumeric_
```

任意用関数は正規化後の空欄をエラーにせず、空文字として返す。両列を同じ必須バリデータで検証する実装へ戻してはならない。

## 7. 行番号とセル番地

エラー行は、ヘッダーからの相対行ではなく、Google スプレッドシートの物理行番号で表示する。

ヘッダー行が2行目の場合:

```text
2行目: ヘッダー
3行目: 1件目のデータ
4行目: 2件目のデータ
```

`SA/TA`がJ列なら、1件目の対象セルは`J3`、2件目は`J4`である。

空欄は正常なため、空欄についてエラーは表示しない。非空欄の不正値では次の形式を基本とする。

```text
シート上の4行目（対象セル J4）の「SA/TA」は、空欄または半角英数字で入力してください。
```

## 8. 検出値の表示

不正な非空欄値の場合は、次を利用者向けダイアログへ表示する。

- JSON形式でエスケープした値のプレビュー
- 文字数
- 先頭20文字までのUnicodeコードポイント
- 正規化後の値

例:

```text
検出値: "B65-655"（文字数 7、コードポイント U+0042 U+0036 U+0035 U+002D U+0036 U+0035 U+0035）
正規化後: "B65-655"（文字数 7、コードポイント ...）
```

学生情報を実行ログへ出力せず、利用者向けダイアログだけに表示する。値のプレビューは最大40文字、コードポイントは最大20文字とする。

## 9. 空欄の扱い

- 学籍番号が正規化後に空欄ならエラーとする。
- `SA/TA`が正規化後に空欄なら正常とする。
- `SA/TA`の空欄はTSVの4列目の空セルとして出力する。
- 後続の日付列を左へ詰めない。
- `SA/TAが空欄です`というエラーを表示しない。

## 10. テスト要件

- ヘッダー2行目、データ3行目で`J3`を算出できる。
- `B65655`を正常値として扱う。
- 前後空白、全角英数字、ゼロ幅文字を含む`B65655`を正規化できる。
- `SA/TA`空欄を正常値として扱う。
- 空白だけ、ゼロ幅文字だけの`SA/TA`を空文字へ正規化できる。
- 3行目が正常、4行目が非空欄の不正値なら`J4`を表示する。
- `B65-655`のエラーに`U+002D`を表示する。
- 空欄を含むTSVで列位置を維持する。
- 最大1,000人・304列の処理を維持する。
